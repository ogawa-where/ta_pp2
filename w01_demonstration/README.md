# w01 デモンストレーション

## 1. 仮想環境の準備

山口先生の [pp2 リポジトリ](https://github.com/yamasound/pp2) の `w01/command.sh` を実行し，仮想環境を構築します．

```bash
git clone https://github.com/yamasound/pp2.git
cd pp2/w01
./command.sh
```

## 2. 実行

このディレクトリの `command.sh` を実行します．追加モジュールのインストール後にプログラムが実行され，生成された `output/output.docx` が開きます．

```bash
./command.sh
```
